# Security

Report vulnerabilities privately with GitHub's **Report a vulnerability** button on the
repository's Security tab. If it is unavailable, open an issue asking for a private contact,
without details.

Never include session cookies, passwords, trip keys (the 16-letter part of trip URLs) or
private itinerary data in reports or issues. Do not test against other people's trips or put load
on Wanderlog's services. Fixes land on the latest release.

The server's safeguards are described in the [tool reference](docs/tools.md#safety-model) and
[privacy notes](PRIVACY.md).
